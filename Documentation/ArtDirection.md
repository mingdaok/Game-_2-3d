# 环境与建模升级 · 0.3.0

视觉方向：青灰石造遗迹、旧黄铜星盘与暖色烛火。主要路线使用明亮的石台顶沿；远景使用低对比拱廊，减少四向折叠时的干扰。

## 原创模型

`Tools/make_models.py` 保留可重建的几何源代码，`Tools/GeneratedModels` 保留 OBJ 模型；UE 资产位于 `/Game/Foldlight/Art/Models`。

| SM_Stone | 倒角石台、檐口与碎石 | 60 |

以上模型由本工作区脚本制作，没有新增外部素材下载或许可依赖。已有火焰 Niagara 资源与中文字体继续使用项目中的版本。

## 场景组合

- 五关分别采用青灰、靛灰、苔绿、炉火褐与星空蓝配色。
- 前后两层拱廊、悬挂晶灯、远处星盘、断裂檐口与下方碎石形成空间层次。
- 远景按当前投影方向退到最远的玩法物体后方，避免四向换面后遮住远处平台或终点。
- 可行走平台增加四面一致的黄铜边饰、石材接缝与地面刻纹。
- 出口改为带双环星盘、刻度及晶体柱的传送门；火印机关改为雕刻底座与晶体核心。
- 蜡烛角色增加融蜡边缘、蜡滴、披风褶皱、领圈与胸针；火焰从椭球换成专门的火焰网格。
- 石材采用世界空间程序颗粒；黄铜使用独立金属度和粗糙度参数。

## 实现边界

装饰网格均不参与碰撞；平台与机关仍使用原有逻辑碰撞体。四向选择、投影尺寸与落点恢复规则不变。重复远景按网格与材质组合使用实例化组件，非当前关卡的环境整体隐藏。这些是结构上的开销控制，并不等于已经完成帧率基准评估。

这是第一轮风格化美术升级，仍未加入骨骼角色动画、手绘贴图、完整LOD梯度或正式美术资源生产管线。

重建：先运行 `python Tools/make_models.py`，再以 UE Python commandlet 执行 `Tools/import_art.py`，最后执行 `Tools/Package_Windows.bat`。
